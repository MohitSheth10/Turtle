# Turtle Drawing

A 180-line Python program that draws a picture using the `turtle` module. I wrote it in 7th grade.

I picked an image online and rebuilt it by hand. There is no tracing tool: I worked out the angles and distances with math, then wrote each line so the turtle moves to build the picture.

Every line is written by me.

## How to Run

You need Python 3. The `turtle` module comes with it.

```bash
python "turtle in turtle module.py"
```
